## 📦 Installation

Clone the repo and install dependencies:

```bash
git clone https://github.com/yourusername/portfolio.git
cd portfolio
npm install
```

Run the development server:

```bash
ng serve
```

Then open [http://localhost:4200](http://localhost:4200) in your browser.
